# Логотип в шапке

Положите сюда файл логотипа с одним из имён:

- `logo.svg` (лучше всего — чёткий на любом экране)
- `logo.png`, `logo.webp` или `logo.jpg`

и обновите страницу — логотип появится в шапке слева. Пересобирать ничего не нужно.

Шапка белая, поэтому подойдёт обычный (тёмный или цветной) вариант логотипа.
Перед использованием логотипа спонсора убедитесь, что правила хакатона это разрешают.
