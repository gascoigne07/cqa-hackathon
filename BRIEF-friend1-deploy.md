# Друг №1 — Деплой + живое демо (DevOps/демо-лид)

## Миссия
У сильного конкурента приложение **задеплоено на живой URL**. Нам нужно то же + **бэкап на случай провала демо**. Это твоя зона — инфраструктура, не трогаешь код оценки.

## Доступ
Мирас добавит тебя в приватный репозиторий `github.com/dissjbchd/cqa-hackathon`. Локальный запуск: нужен **Python 3.10+** (бери `python3.12`), затем `./start.sh` → открыть http://localhost:8000. Бэкенд сам отдаёт собранный фронт из `frontend/dist`.

## Задачи
1. **Dockerfile** для бэкенда: python:3.12-slim → `pip install -r backend/requirements.txt` → копировать `backend/` и `frontend/dist` → запуск `uvicorn app.main:app --host 0.0.0.0 --port 8000` (рабочая директория `backend`). Один контейнер = и API, и фронт.
2. **Деплой** на Render или Railway (free tier): подключить репо, start-команду как выше. **Переменные окружения даст Мирас** (`CQA_API_URL` + ключи) — в код/гит НЕ коммитить. Пока наш Claude-судья не вживлён — деплой с `CQA_DEFAULT_PROVIDER=mock`, чтобы URL уже работал; переключим на `claude` после интеграции.
3. **Проверить живой URL** end-to-end: список диалогов → «Оценить» → апелляция → правка чек-листа.
4. **Бэкап-видео**: запиши экран на 5 минут по сценарию демо из `README.md` (раздел «Сценарий демонстрации»). Это страховка, если на сцене живое упадёт.
5. **Подготовить демо-машину**: заранее загрузить данные, оценить 3-4 красивых диалога, завести одну апелляцию — чтобы демо шло без ожиданий.

## НЕ трогать
`backend/app/scorers/*` и `backend/app/service.py` — их правит ML-команда (мы с Мирасом). Только деплой/инфра-файлы.

## Готово, когда
Есть рабочий публичный URL + 5-мин бэкап-видео + отрепетированная демо-машина.
