# Друг №2 — Экран «Точность» (фича, которая выигрывает)

## Миссия
Главный критерий жюри — **точность к эталону**. У конкурентов её почти никто не показывает. Ты строишь **экран, который визуально ДОКАЗЫВАЕТ нашу точность** — это центр питча.

## Данные (уже готовы — не ждёшь никого)
Файл `frontend/src/data/calibration.json` — **реальные цифры** нашей калибровки на 35 вручную-размеченных диалогах. Просто импортируй его в React (`import data from "../data/calibration.json"`).

## Доступ
Мирас добавит тебя в репо `github.com/dissjbchd/cqa-hackathon`. Фронт: React 18 + TypeScript + Vite + **Fluent UI v9**, папка `frontend/src`. Запуск: `cd frontend && npm install && npm run dev` → http://localhost:5173.

## Задачи
1. **Новый экран «Точность»**: добавь маршрут в `src/router.ts` и пункт в навигацию (посмотри, как сделаны существующие экраны в `src/screens/`).
2. **Отрисуй из `calibration.json`:**
   - **Карточки сверху:** MAE **7.58** из 100 · в пределах ±10: **26/35** · грубые ошибки **8/8 (100%)** · эталон **35 диалогов**.
   - **Бар-чарт по критериям:** `criteria[].agreement_pct` (c01–c08); для шкальных (c04, c06) покажи ещё `within_step_pct` («в пределах одной ступени»).
   - **Таблица/скаттер AI vs Человек:** по `dialogs[]` — `human` против `ai` по каждому диалогу, цветом выдели совпадения, подсвети крупные расхождения.
   - **Подпись-фрейм:** «Откалибровано на 35 диалогах, размеченных вручную экспертом».
3. **Красиво** — Fluent UI, зелёная тема Freedom из `src/theme.ts`. Это то, что жюри увидит как наше доказательство точности.

## Смысл для питча
Жюри видит: мы не просто доверяем ИИ — мы **измерили** его против человека и показываем числом. Конкуренты в основном этого не делают. Это наш козырь по критерию №1.

Полированный экран «Точность» рендерит `calibration.json`, можно показать на сцене как доказательство точности.
